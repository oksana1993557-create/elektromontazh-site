ЭЛЕКТРОМОНТАЖ / АЛМАЗНОЕ БУРЕНИЕ — стартовый HTML-макет

1. Откройте index.html в браузере (или запустите локальный сервер).
2. Ваш логотип уже установлен в assets/logo-light.png (прозрачный фон).
   В assets/logo-dark.png — вариант для светлого фона.
3. Изображения в css/style.css пока демонстрационные, загружаются с Unsplash.
   Замените ссылки в классах photo-hero, photo-electrical, photo-drilling,
   photo-project-1, photo-project-2, photo-project-3 на фото ваших работ.
   Для стабильной работы лучше хранить изображения локально в assets/.
4. Ссылки electrical.html и drilling.html — заготовки будущих разделов.
5. Форма пока НЕ отправляет заявки на сервер: открывает почтовую программу
   с подготовленным письмом без адресата. Для рабочего сайта нужен обработчик
   или сервис форм, а также реальные контакты и политика обработки данных.
6. Реальные город, адрес, телефон, юридические сведения, перечень услуг,
   цены и характеристики работ пока не внесены — их нужно согласовать.
7. Следующий этап: внутренние SEO-страницы, кейсы с реальными фото,
   sitemap.xml, robots.txt, микроразметка и обработчик заявок.
